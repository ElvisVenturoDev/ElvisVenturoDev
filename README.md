## 👨‍💻 Sobre mí

¡Bienvenido a mi espacio de desarrollo! 🚀

Soy estudiante de **Análisis de Sistemas Empresariales**, interesado en el desarrollo de software, la arquitectura de sistemas, las bases de datos y la infraestructura en la nube.

Me gusta convertir ideas en soluciones tecnológicas funcionales, diseñar interfaces intuitivas y aprender nuevas herramientas que me permitan desarrollar aplicaciones cada vez mejores.

- 🎓 Formación en Análisis de Sistemas Empresariales.
- 💻 Desarrollo de aplicaciones con Java, JavaFX y Python.
- 🌐 Desarrollo web con HTML, CSS y JavaScript.
- 🎨 Diseño de interfaces y prototipos con Figma.
- ☁️ Despliegue y configuración de servicios en AWS EC2.
- 🐳 Contenerización y despliegue de aplicaciones con Docker.
- 🗄️ Diseño y administración de bases de datos MySQL.
- 📨 Exploración de servicios de bases de datos y mensajería con Aiven.
- 🐧 Administración y trabajo en entornos Linux.
- 🌿 Control de versiones y colaboración con Git y GitHub.
